# Opening data

`a.tsv` … `e.tsv` are the [Lichess chess-openings](https://github.com/lichess-org/chess-openings) dataset (columns: ECO code, opening name, moves in SAN). The dataset is released under the CC0 Public Domain Dedication. The files are embedded in the API assembly and used by `OpeningClassifier`.

To update them, download the five files from the repository's master branch into this folder.
