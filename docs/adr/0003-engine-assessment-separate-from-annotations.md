# Engine Assessment is kept separate from the Owner's Annotations

Unlike ChessBase, Game Analysis does not write `??` marks or engine lines into the Game. Its output is stored as a separate Engine Assessment shown alongside the Game, and it becomes Annotations or Variations only when the Owner explicitly copies it in. This keeps the Owner's own commentary clean, and re-running analysis with stronger settings never overwrites anything the Owner wrote. The Owner will review this choice once it is built.
